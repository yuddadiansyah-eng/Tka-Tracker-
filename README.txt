TKA TRACKER — PWA

Fitur:
- Dashboard
- Checklist materi TKA Bahasa Indonesia, Matematika, Kimia
- Jadwal Belajar
- Statistik
- Target TKA
- Penyimpanan progres lokal
- Install ke layar utama
- Offline setelah aset aplikasi tersimpan

Cara pakai:
1. Upload seluruh file ke hosting HTTPS.
2. Buka index.html melalui alamat HTTPS di Chrome Android.
3. Tekan Install / Tambahkan ke layar utama.
4. Data tersimpan di browser perangkat.

Untuk pengujian lokal, gunakan server lokal (bukan file://), misalnya VS Code Live Server.
