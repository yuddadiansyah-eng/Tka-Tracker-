# TKA Master

Prototype aplikasi belajar TKA mobile-first.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser modern.
3. Data checklist tersimpan otomatis di LocalStorage browser.

## Fitur
- Dashboard dan progress materi
- Checklist seluruh materi yang diberikan
- Jadwal belajar
- Statistik dan analisis sederhana
- Target skor TKA
- Latihan soal mini
- Dark mode
- Responsive mobile/desktop

Catatan: ini adalah prototype frontend statis; belum memiliki backend, akun, sinkronisasi cloud, bank soal lengkap, atau notifikasi push.
